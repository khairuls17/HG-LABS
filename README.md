# HG Labs — Midnight Space

> midnight coding & weird internet experiments

HG Labs is an immersive interactive developer sanctuary built for late-night coding sessions, atmospheric internet experiences, and experimental web interactions.

This project is not a traditional portfolio or corporate SaaS application.

It is designed to feel like:
- a midnight coding workspace
- a cozy digital lab
- a rainy cyber-inspired internet sanctuary
- an interactive developer environment
- a modern atmospheric web experience
